The page loaded, but the studio didn’t start

  1. Hard-refresh this tab (Ctrl+Shift+R / Cmd+Shift+R) — a cached or half-uploaded shell is the most common cause.
  2. Open DevTools → Console. A red line there names the fault exactly: Refused to execute inline script … Content Security Policy means the host/proxy is blocking the script; 404 … /assets/ means the uploaded file is incomplete.
  3. Confirm you uploaded the single-file build (dist/index.html, ≈ 400 kB with one inline <script>) — not a file that points at /assets/*.js, which 404s when only the HTML is present.
